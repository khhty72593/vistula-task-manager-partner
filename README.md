# Task Manager

## Project Description
A simple Task Manager web application built with HTML, CSS, JavaScript and Supabase.

The application allows users to manage their tasks online.

## Features
- Add new tasks
- View all tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Save tasks in Supabase database

## Technologies Used
- HTML
- CSS
- JavaScript
- Supabase REST API
- GitHub Pages

## Project Files
- `index.html` — main application page
- `app.js` — application logic and Supabase API requests
- `config.json` — Supabase project configuration

## Setup
1. Clone this repository.
2. Configure `config.json` with your Supabase Project URL and Publishable key.
3. Open `index.html` using Live Server.
